# i. 계열 추가

C jsrc/v.c의 jtiota/jtjico1 및 jsrc/vi.c의 jtindexofsub를 참조하고 독립 Rust 구현을 추가했다. x i. y와 x i: y는 첫/마지막 항목 위치를 반환하며 미발견은 x의 첫 축 길이다. scalar x는 항목 1개로 취급한다. 항목 shape 불일치는 C와 같이 미발견이며 빈 항목도 비교한다.

정수·bool 원소 검색은 exact i64 hash로 처리해 큰 정수의 f64 변환 손실을 피한다. 실수 혼합은 기존 J tolerance 비교, 문자와 다차원 항목은 순차 비교다. 비정수 tolerant hashing 및 다차원 hash 최적화는 미구현이다. HashMap 예약과 결과 할당은 실패 시 limit error로 반환한다.

i: monad는 정수/반정수 스칼라, I. monad는 scalar/vector 비음수 정수 입력을 지원한다. 복소수·배열 i:·고차원 I.·dyadic I.는 지원하지 않는다. 기존 i. monad 지원 범위는 유지한다.

차등 98개 사례를 추가해 전체 1831개(생성 상태 검사 800개 포함)를 비교한다. 중복·미발견·행 단위 검색·빈 항목·문자/숫자 불일치·tolerance·i64 정밀도·간격·인덱스 반복을 포함한다. Rust 일반 테스트는 기본/portable 각 29개이며 별도 문서 수명 테스트 1개가 있다. 실제 검증은 C 두 빌드 × Rust 두 경로에서 수행하며 기존 j64 타입 차이 1건은 분리한다. 새 기능의 속도 우위는 측정하지 않았으므로 주장하지 않는다.

## e. / E. 보완

검색 계열 범위에 e. 멤버십 및 E. 패턴 시작 위치를 추가한다. e.는 역방향 index-of의 미발견 인덱스를 Bool로 변환한다. E.는 scalar/vector/string의 겹치는 패턴을 순차 비교한다. 빈 패턴은 존재하는 모든 출력 위치에서 참이고 빈 검색 대상은 빈 결과다. E. 다차원은 명시적 미지원이다. 현재 E.의 최악 복잡도는 O(대상 길이 × 패턴 길이)이며 성능 최적화는 별도 과제다.

73개 C 차등 사례와 Rust 회귀 테스트 1개를 추가한다. 문자/숫자 조합, 빈 값, scalar, 중복·겹침, 다차원 멤버십을 포함한다.

C 비교에서 벡터 패턴을 스칼라 대상에 검색할 때 rank error가 필요함을 발견해 수정하고 회귀 사례로 고정했다. 새로운 코퍼스는 1904개다. 기본/portable 각각 일반 테스트 30개와 문서 수명 테스트를 수행한다. C j64의 기존 타입 차이 1건은 계속 별도 처리한다.
