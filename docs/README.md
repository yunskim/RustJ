# 문서 체계 인덱스

공통 역할 체계: [commonplace의 문서 체계 v1](https://github.com/yunskim/commonplace/blob/main/docs/DOCUMENT_SYSTEM.md) (Private; 접근 권한 필요).

| 역할 | 현재 정본 / 경로 |
| --- | --- |
| specification | [PROJECT.ko.md](../PROJECT.ko.md), [프로젝트 설계 장](project/) |
| decisions | 설계 정본 내 결정 및 관련 문서; 독립 ADR 여부 추후 조사 |

| verification | 프로젝트 테스트 및 검증 기록; 전체 목록 추후 조사 |
| research | [기존 연구 문서](research/) — 개인 연구와 공식 계약 분리 검토 대상 |

이 인덱스는 기존 문서의 경로를 변경하지 않는다. RustJ에는 정제된 공개 문서만 유지하고 탐색적 원문은 Private commonplace에 보존한 후 정리한다.
